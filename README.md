Online Food Delivery Analytics Dashboard Using Power BI
Project Overview
This project uses Power BI to analyze food delivery data. It helps
understand orders, revenue, delivery performance, cancellations, and
customer ratings through charts and visualizations.
Objectives
- Analyze total orders and revenue.
- Calculate Average Order Value (AOV).
- Check delivery time and delays.
- Analyze cancellations and customer ratings.
- Compare restaurants and food categories.
Tools Used
- Power BI -- Dashboard creation
- Power Query -- Data cleaning
- DAX -- KPI calculations
Dashboard Features
- Total Orders
- Total Revenue
- Average Order Value
- Average Delivery Time
- On-Time Delivery
- Cancellation Rate
- Revenue by Category and Restaurant
- Customer Ratings
- Interactive Filters
Project Workflow
1. Import the dataset.
2. Clean the data using Power Query.
3. Create DAX measures.
4. Build charts and KPI cards.
5. Analyze the results using the dashboard.
How to Run
1. Install Power BI Desktop.
2. Download the project files.
3. Open the .pbix file.
4. Refresh the data if required.
Outcome
This project demonstrates data visualization, data cleaning, KPI
calculations, and basic business analysis using Power BI.
